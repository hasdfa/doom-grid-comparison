Method

Master 2ae53b9ee2cb vs data-source da4474be8f3d. Passes 1–10: T3 headless Chrome 157. Passes 11–20: headed Google Chrome 154.0.8037.57 on the VNC desktop (:1), automated through Playwright with an isolated persistent profile. Both use 1280 × 800 viewport and DPR 2. One tab reused with a full navigation per observation. A paused TanStack 96 × 60 grid stays mounted. Odd passes run master first; even passes run data-source first. The original 10-pass dataset is included unchanged; the earlier exploratory two-pass dataset is excluded. Combined averages give both browser groups equal weight. Browser version, rendering mode, time, and system load differ between groups, so the combined result is not a single-browser estimate.

One-minute server load ranged from 1.66 to 54.56 on 16 logical CPUs, sampled after each observation. Browser remained visible. Timing starts after cell readiness; mounting excluded.

DOOM: fresh engine, one-second warmup, three-second forward walk and Ctrl every 500 ms. Synthetic: 60 full-cell updates after eight warmups, animation-frame paced. JS time excludes browser rendering. P95 values are averaged per-run P95 intervals, not a pooled percentile. All metrics come from rounded UI values (FPS 0.1; JS 0.01 ms; P95 0.1 ms).
