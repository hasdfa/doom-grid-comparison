# Grid experiment

The game leads. A dark charcoal shell (#171814) surrounds a full-width pixel grid.
Warm white text (#f4f1e8), muted olive gray (#b8b9ad), and acid yellow (#e1f288) distinguish controls and focus.
Use a compact header, renderer tabs, one game stage, and an instruction strip.
Keep cell gaps visible. Scale the complete stage on narrow screens and provide touch controls.
Use 8px spacing increments, 6px control corners, and 44px minimum controls.
