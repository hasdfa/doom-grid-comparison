# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, TypeScript, Vite. Static build published to seemyslop.

## Product Purpose

Recreate the referenced playable DOOM table demo with MUI X Data Grid Premium and Base UI Mosaic. Add AG Grid and TanStack Table for comparison.

## Capabilities and Constraints

One shared game engine, four interchangeable renderers, 23,040 colored cells, keyboard controls, and measured FPS.
The target is 30 FPS, not a guaranteed benchmark. Game assets and source notices remain available in the static build.
